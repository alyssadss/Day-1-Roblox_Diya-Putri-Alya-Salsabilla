## DOKUMENTASI KEGIATAN WORKSHOP
## 1. Rangkuman Materi Workshop
Materi workshop Day 1 membahas penggunaan AI melalui Prompt Engineering, yaitu cara menyusun instruksi dengan memperhatikan Role, Task, Context, dan Format agar hasil yang diberikan sesuai kebutuhan. Selain itu, dibahas juga pengenalan Git dan GitHub sebagai alat untuk mengelola serta menyimpan perubahan proyek. Materi Git mencakup Git Workflow yang terdiri dari Working Directory, Staging Area, dan Git Directory, serta beberapa perintah dasar seperti git init, git add, git commit, git push, dan git pull. Materi kemudian dilanjutkan dengan praktik membuat aplikasi Student Task Planner menggunakan bantuan AI dan mengelola proyek tersebut melalui GitHub.
## 2. Poin-poin penting
- Membuat prompt AI tidak cukup hanya dengan memberikan perintah singkat, tetapi juga perlu memperhatikan konteks dan format hasil yang diinginkan.
- Struktur Role, Task, Context, dan Format dapat membantu menghasilkan prompt yang lebih terarah.
- Git digunakan untuk melacak perubahan proyek, sedangkan GitHub menjadi tempat penyimpanan repository secara online.
- Git memiliki beberapa tahapan dalam mengelola perubahan, yaitu Working Directory, Staging Area, dan Git Directory.
- Perintah commit dan push memiliki fungsi yang berbeda dalam proses penyimpanan dan pengiriman perubahan.
- AI dapat dimanfaatkan untuk membantu proses pembuatan aplikasi, sedangkan GitHub membantu menyimpan dan mengelola perkembangan proyek.
## 3. Pendapat Pribadi
Menurut saya, workshop ini memberikan pengalaman dan pengetahuan baru, terutama mengenai penggunaan AI serta pengenalan Git dan GitHub yang sebelumnya belum terlalu saya pahami. Materi yang disampaikan juga memberikan gambaran bagaimana teknologi tersebut dapat membantu proses pengerjaan proyek menjadi lebih terarah dan terorganisir.
Melalui workshop ini, saya menjadi lebih memahami pentingnya membuat instruksi yang jelas saat menggunakan AI serta mengetahui cara menyimpan dan mengelola perubahan proyek menggunakan GitHub. Saya berharap ilmu yang diperoleh dapat diterapkan dalam kegiatan perkuliahan maupun proyek berikutnya, khususnya di bidang Teknik Multimedia Digital.
